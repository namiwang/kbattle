## Deviations from the plan

- Four doer instruction fields, not five: `escalate` is fixed by kbattle (DESIGN §5.4). DESIGN §7's "five short fields" should read "four" (recommended edit for the designer).
- The key is stored as plain text (shared with the v0.6 spike page); prompts and config as JSON under `kbattle:v1:*`.
- Validation runs live under the Run button (the button stays disabled until v4.2). Without a key the prompted count is shown and validated as 0 but the saved value is kept, so a first-time visitor keeps the "1 prompted" default once a key is saved.
- `DEFAULT_PROMPTS` are placeholders in `web/src/ui/defaults.ts`; v3.4 replaces them with a re-export from brain.

## Carry-forward risks

- Reset to defaults has no undo; doer fields are single-line; no cross-tab sync. All acceptable for the PoC.
