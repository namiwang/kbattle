## Carry-forward risks

- A crafted log with a huge tick makes `indexLog` allocate one frame per tick; the schema needs a bound (ISSUES I-014, assigned to v1.5).
- Headless Chromium uses SwiftShader: each new WebGL context stalls about 430 ms on its first present; measure to `firstFrame`, never by frame counts.
