## Deviations from the plan

- The wall floor (`minWallMsPerTick`) waits before each step rather than after, so a slow due tick followed by a fast tick cannot step early (row 31).
- Cancel completes the tick in progress, logs in-flight calls as faults, then writes `MatchEnd { ranking: [] }`.
- `Tick` events carry an optional `near` field (ISSUES I-016); event ticks are bounded (I-014); Spawn events are rounded like Tick rows.
- Extra exports: `botProviders`, `replayMatch`, `rankAgents`, `spawnEvents`, `tickEvent`.

## Carry-forward risks

- Worst case log size with full Clef probability maps (16 agents alive all match) is 6.65 MB; the Worker doer client rounds probabilities to 4 decimals before returning (ISSUES I-018).
- Thinker calls still in flight at match end are not logged (no final poll); accepted for the PoC.
